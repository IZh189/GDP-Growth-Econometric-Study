# GDP Growth Econometric Study

Econometric analysis of cross-country GDP growth using multiple regression models and robustness tests based on the Sala-i-Martin growth framework.

## Overview

This project investigates the determinants of economic growth across countries using econometric methods in R.

## Technologies

- R
- Multiple Linear Regression
- Econometrics
- Statistical Analysis

## Repository Structure

- `scripts/` - R source code
- `report/` - final project report
